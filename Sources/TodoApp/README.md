# floating-ui

`main.swift` 建立 AppKit 生命周期与编辑菜单；`FloatingController` 管理球、面板、菜单栏、固定锚点和独立窗口输入状态；`AppModel` 保存界面状态/草稿，调用共享 Store；`Views` 提供清单、详情、附件、项目设置和回收站。

UI 每 0.7 秒读取已提交快照。没有修改的详情随外部更新刷新；脏草稿保留旧版本，保存时检测冲突。返回、锁定和退出时先保存；失败不离开。清单视图在详情/设置打开时保留自身滚动状态并隐藏，禁止命中和无障碍访问；返回时恢复原位置。

清单、顶部选择器和底部输入统一左右边距；任务展开按钮放在行右侧，无子任务不占位。三个缩放角保留透明命中区和悬停光标，不显示常驻图标。任务行按稳定 ID 读取当前快照，避免从已完成分组迁回待办时显示旧状态。

`QuickAddView` 默认只显示右下角加号；图标 26 pt、点击区 44×44 pt，同一固定右下角的容器从 44 pt 扩展至 72 pt 高输入区，0.42 秒动画，展开后再聚焦。输入区顶部 6 pt，内容从顶部按实际高度紧凑排布，不用底对齐留下大块空白；输入文字与加号中心对齐。没有收起叉按钮。`OutsideClickBoundary` 用本窗口内的原生事件监视判断区域外点击，返回原事件，不吞掉或重放点击；窗口失去 key、操作工具栏/切换页面也会收起。收起时结束编辑，标题/项目/父任务草稿留在 `AppModel`，不会因输入控件移除而清空；成功创建才清空。此草稿保留范围是本次应用运行，未增加跨重启持久化。空列表在剩余清单区域以 14/12 pt 小字号居中显示。

`ResizeCursor` 根据缩放轴与展开方向选择双向箭头：水平、垂直、左上—右下或右上—左下。macOS 15+ 使用原生 `NSCursor.frameResize`，macOS 14 使用原生水平/垂直光标与带黑白描边的斜向兼容光标。只改变指针，不改变固定锚点缩放约束。

`TodoHostingView` 在布局时统一处理内容树中的所有 `NSScrollView`，包含后续打开的设置/回收站和嵌套 `TextEditor`；纵横滚动条替换为 `ThinScroller`。只覆盖滑块与轨道绘制，滑块 3 pt，不缩窄原生 frame/命中区，不重写滚轮、拖动或键盘逻辑。保留目标/action、进度、滑块比例和系统滚动条样式，支持原生 overlay 渐隐；不修改系统偏好。

各页面以待办详情为样式基准：根 `ContentView` 统一 13 pt 正文字号、小尺寸 bordered 普通按钮和中性 tint，避免设置与回收站继承旧绿色样式；待保存按钮蓝色、删除红色，保存后显示次级文字。详情、设置、回收站内容区统一 14 pt 横向边距、12 pt 纵向边距与主间距，设置项目输入框复用详情的淡色圆角背景、10/8 pt 内边距；小节标题 13 pt semibold，说明文字使用次级样式。

详情仅在有祖先时显示路径。参考提醒事项的视觉样式：20 pt 可换行标题与 13 pt 备注合为圆角编辑组，状态/优先级/颜色及截止采用图标、名称、右侧原生选择器的横向分组行；12 pt 内边距、12 pt 圆角、中性浅层底色与细分隔线。备注从单行 22 pt 随内容增长到最高 152 pt，超过上限内部滚动，删减后缩回。附件、子任务、移动和删除使用一致分组样式，详情字段停止编辑 400 ms 后自动保存，离开/退出时立即保存，成功静默；移除保存和读取按钮及已保存占位。不同字段并发自动合并，同字段冲突保留输入并要求确认。只改样式，没有增加提醒、标签等功能；其余页面根样式与清单保持原状。

`Toast` / `ToastView` 负责非阻断提示，`AppModel.notify` 统一触发成功（绿）、错误（红）、提醒（黄）。浮层在根视图底部覆盖显示，动画只作用于浮层，3 秒自动关闭，叉按钮手动关闭；新事件取消旧计时并重新计时。轮询的相同持续错误只提示一次，避免不断续期。确认删除等对话框保持原有确认流程。

面板置顶使用 `.floating`，球使用高于 `.floating` 一级的独立窗口层级，防止面板获得焦点或打开设置时遮挡球；不依赖一次性的 `orderFront` 顺序。锁定使用 `ignoresMouseEvents`、禁止成为 key、释放 first responder；不捕获或重放输入，不请求辅助功能/屏幕录制权限。球独立且可交互，菜单可解锁，设置入口先解锁。每次启动不恢复锁定。

`BallView.acceptsFirstMouse` 返回 true，允许其他应用或窗口有焦点时首次按下直接进入原有拖动事件链；移动超过 4 pt 后联动球与面板，松手不触发单击。此设置与键盘 `acceptsFirstResponder` 分开，不通过主动激活应用或全局事件监听实现。

共用顶部的 padding 后挂载 `HeaderDragArea` 原生背景视图，只接收控件之外的空白区域输入；`HeaderDragView` 接受首次按下并复用 `FloatingController.move`，超过 4 pt 后移动球与面板、松手保存位置，空白单击不折叠。Picker 和按钮在前景保留命中，锁定时继续由整个面板的 `ignoresMouseEvents` 穿透。`swift test --filter HeaderDragTests` 验证阈值、联动、不误折叠和结束状态清理。

透明度仅作用于背景，提高对比度/减少透明时使用实色背景。窗口偏好单独保存于 window.json。显示器变动时按实际屏幕可见区域回收位置；实际多屏、Spaces 与穿透测试限制见 [验收报告](../../docs/acceptance/macos-floating-todo.md)。

启动：根目录 `./scripts/run.sh`。运行开发测试时使用 `NEXT_ONE_HOME` 隔离。原生窗口测试须操作实际应用；几何单元测试不替代拖动、置顶和跨应用输入验证。

全部项目清单按绑定项目显示透明 1 pt 彩色边框；9 pt 项目名嵌在顶边真实缺口，点击名称切换项目折叠，复用窗口 collapsed 偏好（project- 前缀）。不显示展开箭头或空项目；未分类直接显示原任务树。项目颜色按稳定项目数组位置分配色相，深浅模式分别调亮度。单项目筛选保持无框任务树。优先级使用独立 PriorityBadge：一般/比较紧急/紧急对应 low/medium/high，绿/黄/红圆角背景白字；共享 label 保证详情及右键菜单名称一致。

项目分组保留 10 pt 内边距，同时外扩 10 pt；框内与框外任务行使用相同可用宽度，边框不占用任务内容宽度。

项目收起时仅保留 2 pt 横线与标题缺口，不画侧边和底边；展开恢复 1 pt 项目框。

项目折叠采用 0.45 秒缓入缓出，实际内容先测量自然高度，再按展开状态改变可见高度并裁剪。折叠不移除任务视图，但禁用命中与辅助功能访问；边框 Shape 插值合并为横线，减少动态效果时缩短动画。

`TaskDragging.swift` 使用应用内鼠标追踪，保留 mouseDown/mouseDragged/mouseUp 同一条事件链；标题和留白按住移动超过 4 pt 后显示忽略鼠标的跟手预览窗，不进入系统 NSDraggingSession。单击仍打开详情。每次移动按当前窗口中任务行 bounds 与 visibleRect 的交集判断落点，中部仅允许两个未分类任务合并，边缘显示插入线；松手通过原 Store.place/group 提交并清除预览，Escape 或落到区域外取消。下方末尾区域及项目标题也是明确落点。没有捕获或重放全局系统输入，没有新增权限。

全部项目视图按 boardKeys 混排项目框和未分类任务，组间 BoardDropSlot 单独负责落点和高亮；未分类已完成折叠区在这些插槽之后，不再在该区域下方放置“未分类末尾”拖动入口。项目标题单击折叠，按住移动拖动直接渲染的整个分组组件，松手仅改变顶层位置。落点邻近 8 pt 空隙可归入插槽，任务行命中仍优先按真实边界判断。

清单密度：全部范围顶层 spacing=0，显式插槽 6 pt；组内 spacing=2、顶部 2/底部 6 pt，任务行纵向 padding=3 pt。取消重复分组外部底边留白，保持原点击控件大小及拖动容错。

项目预览尺寸仅从同 boardKey 且 slotPlacement=nil 的分组区域获取，不能取同键插槽；预览复用 ProjectTaskGroup，不依赖 NSHostingView 截图缓存。

设置页每条绑定目录在“重绑”右侧提供 trash 图标；悬停和辅助功能名称明确解除绑定、保留文件/待办，确认后走 project unbind。无目录后显示“绑定文件夹…”入口。

CodexIntegration 只从应用包 Contents/Helpers/next-one 和 Contents/Resources/CodexIntegration/next-one 读取资源，启动时准备到当前 Store.directory/integration 的内容寻址版本目录，完整校验后原子切换 current 链接。设置指令引用 current/bin/next-one 和 current/skills/next-one/SKILL.md，不含源码定位逻辑或编译机路径。缺资源/无法写入时提示错误并支持重试，不影响待办打开。scripts/package-app.sh [debug|release] 构建自包含应用包，run.sh 打包 debug 后启动。用户级 Skill 仍由粘贴指令后的 Codex 安装，应用不自动修改全局配置。


## 多语言

设置顶部的语言选择器支持跟随系统、简体中文、English、日本語、한국어。`LanguageSettings` 保存当前数据目录的 `language.json`，SwiftUI 观察语言状态即时刷新（不使用 `.id` 重建页面），AppKit 通过通知更新主菜单、窗口标题、悬浮球说明；业务数据和草稿不翻译。日期显示使用所选 locale，ISO / 日期存储格式不变。系统语言匹配与英文回退规则见[多语言 Spec](../../docs/spec/2026-10-26/multilingual.md)。

`L` 接收保留模板和插值参数的 `LocalizedText`，通过 TodoCore 的四套 `.strings` 资源读取译文；用户标题、备注、文件名、路径只能作为参数或原文展示，不能作为查找键。`TodoError` 同时保留中文 message 与本地化模板；UI 使用模板翻译，CLI 保留原有中文输出。接入错误在展示时翻译，安装指令按当前语言生成并复制同一全文。

添加界面文案时使用 `L("中文模板")`，在四套资源中添加同键译文；动态值保留 Swift 插值，资源中使用 `%1$@` 等位置参数。运行 `swift test --filter LocalizationTests` 验证键集、占位参数、实际资源读取、语言保存与草稿/数据库不变。打包脚本复制 SwiftPM 资源 bundle 到应用包根目录，符合生成的 Bundle.module 解析路径。

安装版与开发版：共享 Store 的编译期目录规则决定整套数据（含语言、窗口偏好及 integration），release 使用 Next-One-Release，debug 使用 Next-One。打包的 release bundle ID 为 local.todo-ai.release；安装指令始终读取当前 Store.directory，不迁移旧任务、不自动修改全局 Skill。

品牌图标：应用包包含 `paperclip-logo.png`，悬浮球以圆形裁切显示白色竖向回形针与炭黑背景；锁定仍显示白色锁。菜单栏使用原生单色 `paperclip`；缺少 PNG 时回退为系统回形针。应用 ICNS 由同一原图生成，详见[视觉资源](../../Resources/Distribution/README.md)。

产品显示名为 Next One，默认应用包为 `.build/Next One.app`；菜单、窗口、四语安装指令使用新名称。内部 `TodoAI` 可执行文件、资源 bundle、应用标识保持兼容旧版，数据路径兼容规则见下文。

默认新目录不存在且同渠道旧目录存在时，Store 建立新路径到旧目录的符号链接，数据库、附件和偏好仍为同一份；已有新目录不合并，显式目录不自动链接。语言偏好在 Store 准备完毕后加载。NEXT_ONE_HOME 优先，TODO_AI_HOME 仅作为旧调用兼容；安装提示只展示新变量。
