# Next One v0.1.0-preview.1

First public preview · macOS 14+ · Apple Silicon (arm64) · app 0.1.0 build 6

## Download and install

Download **Next-One-0.1.0-preview.1-macos-arm64.dmg** from Assets below. Quit Next One, open the DMG and drag **Next One** into **Applications**. The `.sha256` attachment verifies the download with `shasum -a 256 -c Next-One-0.1.0-preview.1-macos-arm64.dmg.sha256` when both files are in the same directory.

**Unsigned preview:** this package is not Developer ID signed or Apple-notarized. macOS may block a downloaded copy. The downloaded Gatekeeper path, other Macs and Intel builds have not been validated. This is not a production-ready release.

## Included

- A local floating task list with projects, subtasks, notes, attachments and recoverable deletion.
- Shared context with a local coding agent through the bundled `next-one` Skill and CLI.
- The `neo` prefix for natural-language task requests, including PRD breakdown, priorities and handoff notes interpreted by your coding agent.
- Next One branding and the dark paperclip icon; Chinese, English, Japanese and Korean UI.
- Next-One data paths and compatibility links to same-channel legacy storage.
- LICENSE and NOTICE included in both the app and the portable Skill.

## Existing users and agent setup

Release data uses `~/Library/Application Support/Next-One-Release`, separate from development data. When only the same-channel legacy folder exists, the new path links to that store; data is not copied or merged. Do not run two UI instances against the same data.

In **Settings → Codex integration**, copy and send the setup instruction to a local Codex chat to install or update the Skill. Installing the app alone does not update an existing global Skill. Fresh-session automatic Skill discovery is still unverified. Dates stored in tasks are not scheduled notifications.

## Validation and limitations

Release build, DMG CRC, SHA-256, mounted resources, four languages, complete Skill, LICENSE/NOTICE and CLI checks passed. App and CLI binaries match the locally verified running version. Artifact source: `2799e2a`.

Cross-app click-through, multi-display/Spaces/full-screen combinations and some media interactions remain partially unverified. No cloud sync, remote-agent synchronization or background chat monitoring is provided.
