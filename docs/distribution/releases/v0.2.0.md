# Next One 0.2.0 · Pre-release

Turn a task into a Codex conversation, keep dated tasks in Apple Reminders, and make your floating list easier to organize.

## Start Codex work directly from a task

Right-click a task to start a new Codex conversation with its context. Choose an existing Codex project and add optional instructions in a compact window beside your list. The task code and title keep the handoff clear, while your floating list stays visible.

## Apple Reminders and Calendar sync

Enable **Sync to Calendar** and choose your own iCloud Reminders list to sync tasks with due dates. View them in supported versions of Apple Calendar, and check or uncheck them on your iPhone to update their completion status in Next One.

- Sync task titles, descriptions, due dates, and completion status.
- Available lists refresh automatically while Settings is open.
- Attachments stay local, and subtasks appear as separate reminders. High priority does not automatically enable an urgent alarm.
- Use the same Apple Account on Mac and iPhone with iCloud Reminders enabled. Calendar display requires macOS 15 / iOS 18 or later.

## A clearer task list

- **Short task codes:** refer to tasks with codes such as A1 and B2 for quicker lookup and clearer conversations.
- **Project task counts:** see how many tasks belong to each project.
- **One completed section:** completed root tasks appear together at the bottom, grouped by project.
- **Archive completed tasks:** clear finished work from the active list and safely free task codes for reuse.

## A lighter desktop experience

- Set the background opacity as low as 0% while keeping text and the floating button clear.
- When the list is locked, moving your pointer over it fades the panel so you can see what is behind it; moving away restores it.
- Slim, edge-aligned scrollbars remain visible whenever content overflows.
- New tasks start at normal priority, ready to be raised when needed.

## Codex integration that follows app updates

Copy the setup instruction from Settings into a local Codex chat to install or update the Skill and persistent project-work rules. Managed integration uses a stable entry point that follows the bundled CLI and Skill after you update and launch the app, while preserving custom content.

Automatic discovery in a fresh chat still depends on the Codex environment. Next One does not monitor all conversations in the background.

## Download and upgrade

**macOS 14+ · Apple Silicon (arm64)**

Download `Next-One-0.2.0-macos-arm64.dmg` from Assets, quit the previous version, and drag Next One into Applications to replace it. Your existing task data stays in place. A SHA-256 checksum file is included.

The app and DMG are signed with a **Developer ID Application certificate**. Upgrading from an earlier ad-hoc-signed build may require granting Reminders access once again.

This is a **Pre-release** and is **not yet Apple-notarized**; macOS may block a downloaded copy. Intel, multi-display / Spaces / full-screen combinations, and cross-device notification timing have not been comprehensively validated.
