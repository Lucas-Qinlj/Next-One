# Codex 输入框辅助功能聚焦

- 日期：2026-10-27
- 状态：本地实现及匹配/交接自动测试通过，未实机验收
- 需求来源：C3 隐藏后聚焦通过，但两轮自动恢复浮窗失败；用户要求采用权限方案，并在需要授权时跳转系统对应页面。
- 关联：[原交接 Spec](codex-task-handoff.md)、[项目规范](../../../AGENTS.md)。

## 目标与范围

在浮窗最终展开的情况下，将键盘焦点定位到本次 Codex 预填输入框。新增可关闭的“自动聚焦 Codex 输入框”选项，默认关闭；关闭时沿用已通过的隐藏清单交接方案。用户开启后才使用辅助功能权限。不自动发送、点击发送按钮或模拟键盘，不读写 Codex 数据库，不新增后台进程。

## 交互与规则

- 设置提供开关、权限状态与“前往授权”按钮。交接准备阶段若已开启但未授权，保留指令和选择，明确提示，并在交接弹窗提供相同按钮。
- 用户点击前往授权时调用系统辅助功能信任提示，并打开隐私与安全性中的辅助功能页面；系统开关由用户本人开启。回到 Next One 刷新权限，重试须再次由用户点击打开，不自动发送、不反复弹授权窗口。
- 先校验上下文并关闭 sheet，隐藏清单后打开 URL；系统接受后恢复清单，再尝试通过 AXFocused 设置输入焦点。只在 Codex 为前台时查找：优先使用其自报的当前编辑框，须完整匹配本次 prompt 且 AXWindow 属于当前窗口；未命中才遍历当前窗口寻找唯一匹配编辑框。匹配期间只读必要 UI 属性，不记录文本或 URL；应用自报焦点仅用于定位，不代替系统键盘核验。
- 搜索有节点、深度、单次 IPC 超时及整体时间上限。结果不唯一、目标不支持聚焦、授权撤回均失败，不猜控件、不按固定坐标点击。焦点写入前重新核对前台应用、窗口和完整文本，写入后读回核验。
- 等待启动阶段允许交接时原前台应用（非激活面板可能未激活 Next One）及 Next One 保持前台，直到 Codex 出现；用户切到其他应用、在 Next One 操作或启动新交接则取消。成功后停止，不永久监听或反复抢焦点。
- 失败用底部提示告知手动点击输入框；保留浮窗展开，不自动重开会话。URL 打开失败仍恢复交接草稿。
- 重复交接修正：写焦点返回成功后，读回状态允许最多 300 ms 的短暂异步更新，只读确认、不重复写焦点；目标切换、取消或权限撤回停止。设置前控件变化或写请求被拒绝可在 8 秒窗口内重新查找。细分失败提示，并在设置页保留当前运行期间最近一次失败，下一次交接清除；不记录指令、控件文本或截图。
- 系统级核验：仅 Codex 内部报告焦点不算成功；必须核对系统接收键盘输入的应用 PID 和系统焦点元素均属于目标编辑框。系统对象只读取焦点对象身份，不读取其他应用内容。若键盘焦点仍属于 Next One 自身且 Codex 已前台，可请求 Codex AXFrontmost 后设置编辑框焦点；属于其他应用则不夺取。
- 设置页展示本次运行的聚焦状态（等待、确认、停止、具体失败）。自身普通字符事件不再被当作取消依据，避免把焦点错误导致的字符误投当作用户主动操作；原事件不吞掉或重放。鼠标按下、Escape、应用切换及新交接仍取消。
- 权限关闭时不使用 AX；权限不等于预填接口承诺，Codex 当前版本是否暴露可匹配编辑框必须实测。

## 实现计划与边界

1. 添加原生 ApplicationServices 适配与受限查找，复用 AppKit，不引入第三方依赖。
2. 接入交接和设置、权限跳转及四语文案；移除前两轮失败的延时恢复实验。
3. 用隔离测试验证匹配拒绝路径、权限缺失保留草稿与原交接回归；release 打包供用户授予权限后验收。

入口：`Sources/TodoApp/CodexAccessibilityFocus.swift`、`Model.swift`、`Windows.swift`、`CodexHandoffView.swift`、`Views.swift`。配置复用 window.json，不改业务库。核心风格沿用 `guard` 提前返回、局部更新及现有 L 本地化。

## 验收

- `swift test --filter CodexHandoffTests` 与新增聚焦匹配测试通过；`swift build -c release` 通过。
- 未授权不打开新会话、草稿及选择保留；按钮到达系统辅助功能页面，返回后状态刷新。
- 用户授予运行版本 Next One 权限后，真实交接完整预填、清单展开、无需点击 Codex 即可输入，消息不自动发送。
- 手动切换应用或点击清单后不再抢焦点；权限撤回、控件不存在或多重匹配时明确失败。
- Agent 的 Computer Use 禁止访问 Codex，不用新代码绕过工具限制；真实权限及 Codex 聚焦由用户验收，不以 Mock 代替。
