# 全局任务短编号与项目数量

- 日期：2026-10-26
- 状态：已实现；自动测试、真实 CLI 与本机隔离 UI 验证通过
- 来源：用户要求标题前编号、软件内全局唯一、项目名旁统计父子任务。

## 目标、范围与规则
- 每个任务（含父、子、未分类、完成、回收站）在同一数据存储内具有唯一且永久不变的 short_code，原 UUID 仍为内部主键。
- 从 A1 起，数字 1–9 先递增，随后字母按 Excel 式 A…Z、AA…AZ、BA…ZZ、AAA 递增：A9→B1，Z9→AA1，AA9→AB1。数字始终一位，无 0。
- 全局递增计数器在写事务内分配；不按项目或层级重置，删除不回收。创建失败回滚，幂等重试不额外占号。
- 旧任务首次升级按 createdAt、UUID 升序补号，含回收站；不更改标题、状态、关系、revision 和时间。存储版本升级至 2，旧版新连接拒绝打开，升级前应退出旧版应用和 CLI，不支持旧版写入新库。开发/安装渠道仍为不同数据存储。
- CLI 任务引用参数支持 UUID 或大小写不敏感的精确短编号，不进行前缀匹配；统一先解析为 UUID，再执行原业务校验。返回任务保留 UUID，增加 short_code；context 也返回编号。缺失或已删除沿用 not_found，恢复从 trash 取得编号和 revision。
- 仓库内 Skill 支持如 neo 完成 A1：先 get 校验目标/项目及 revision，再局部写入；明确项目与编号归属冲突时澄清。编号自身不构成自动执行授权。
- 清单标题前显示编号：项目框同色、opacity 0.6，字号为标题的 0.8（13→10.4 pt），HStack center 对齐文字行中线；未分类使用中性灰。完成后的编号仍保留，不加删除线。详情/回收站也可识别编号。
- 项目名后显示括号计数，统计该区域任务树内所有未删除父子任务，不受折叠影响。上方包含未完成父任务下已完成子任务，下方只计已完成根任务及后代，避免上下重复。名称与计数作为整体嵌入边框缺口。
