# 中英日韩多语言

- 日期：2026-10-26
- 状态：已验证，已按后续用户授权合并 main 并原位替换现用本地应用；未推送或对外发布
- 需求来源：用户要求为当前 Todo 软件加入中文、英文、日文和韩文。

## 目标与范围

应用界面、菜单、悬浮球辅助说明、确认框、提示、业务错误和 Codex 安装指令支持简体中文、英文、日文、韩文。任务/项目名称、描述、附件名称、路径不翻译。CLI 命令、JSON 字段、状态枚举及默认中文错误输出保持兼容；不翻译 Skill 文档，不引入在线翻译或新依赖。

## 交互与规则

采用实施默认值：设置顶部提供“跟随系统 / 简体中文 / English / 日本語 / 한국어”，初次默认跟随系统。按系统首选语言顺序匹配 zh/en/ja/ko，中文变体均使用简体中文，完全不匹配时使用英文。手动选择即时生效，保存到当前数据目录；跟随系统在启动和系统区域通知后重新解析。语言切换不重建页面、不改变用户数据、编辑草稿、展开状态和业务枚举。日期展示跟随界面语言，存储的仅日期值及 ISO 时间戳不变。系统文件面板内部按钮和 OS 错误由 macOS 自身决定语言。

## 接口与实现

使用 Foundation Bundle 与本地 .strings 资源；SwiftUI 观察语言状态，AppKit 菜单/球标签同步刷新。业务错误保留可翻译模板和参数，CLI 仍读取原中文 message；不按错误码合并不同校验原因。参数按位置插入，不把用户输入作为本地化键。偏好文件独立原子写入，失败提示且不声称保存成功。打包携带资源，不能依赖源码路径。

源文件在 Sources/TodoApp 与 Sources/TodoCore，测试在 Tests；四空格缩进，复用 AppModel 错误处理，示例 `L("设置")`。构建 `swift build`；测试 `swift test`；打包 `./scripts/package-app.sh debug`；CLI 回归 `python3 scripts/cli-smoke.py`。
