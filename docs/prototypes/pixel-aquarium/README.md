## 动效

- 鱼体沿平滑速度方向移动，尾部单独变形摆动，转向逐渐压缩再翻转；不同鱼有独立节奏。
- 水面局部折射与光纹漂移，水中细小颗粒浮动，水光轻微明暗变化。
- 前景水草/软珊瑚独立绘制，根部固定、上部随时间摆动；岩石保持静止。
- 新鱼从水面进入并产生气泡，到期后缓缓上浮淡出。动作不伴随声音。
- 暂停冻结鱼、水、水草；页面隐藏/离开可视区后停止绘制。系统减少动态效果默认暂停。

## 交互与数据边界

三条模拟待办分别代表 0 / 3 / 8 个后代；点击完成按小型 / 中档 / 高档池随机奖励一条。再次点击重新打开，鱼保留；再完成不重复奖励。切换背景只替换景观，不重抽鱼。

大小可在 180–420 px 调整，窄窗口按可用宽度容纳。时间 +1 天用于观察寿命；重新演示恢复虚构初始状态。没有本地持久化，也不代表应用关闭后的真实时间恢复已实现。

所有鱼的寿命暂用用户例子 **12 个月→6 天**。鱼种分档和真实代表寿命尚未定稿；此处不提供真实市场价或生物学寿命结论。

## 验证记录

- JavaScript 语法检查通过，单文件内嵌大小约 702 KB。
- 0 / 1 / 5 / 6 / 10 个后代的分档边界和 12 / 24 个月寿命换算通过；负数量/零寿命被拒绝。
- 实际浏览器：完成后 5→6 条；重新打开仍为 6 条；再次完成仍为 6 条；另外两档完成后 8 条。三种背景可切换且鱼数保持。
- 实际浏览器：推进至第 6 天后活鱼数为 0，离缸动画结束后画面为空缸。
- 实际浏览器：320 px 宽窗口控件换行、任务信息可见；宽度调整到 180 / 420 px 均完整显示。
- 实际浏览器：暂停后两次整页截图像素完全一致；恢复后，水面区域 8,773 / 9,216 像素、左侧水草区域 1,820 / 2,440 像素、鱼游动区域 10,079 / 18,000 像素发生变化。此为动效运行证据，不是原生性能测量。截图位于 [evidence](evidence/)。
- 透明度检查：生成的鱼与植物原图含真正的 alpha=0 像素；浏览器中无白底。素材显示器有时展示透明像素中的 RGB 光晕，实际合成按 alpha 渲染。
