# 可选持续工作规则

以下内容供用户审阅并手动添加到需要接入 Next One 的 Codex 工作规则中。本项目未安装全局 Skill、未修改 Codex 配置。先确保 `todo` 的实际路径可用，以及项目目录已经显式绑定。

```text
在本机项目工作中使用 todo-ai Skill：开始时读取当前目录对应的未完成待办，关联已有事项；仅将用户明确要求的工作记录为任务，开始实际实施时标记进行中，完成后按真实结果更新状态和描述。保留用户修改，使用版本检查和创建幂等键。接口失败明确报告未同步；不把模糊探讨或每次工具调用都写入清单。未匹配目录不得写入其他项目，不直接读写数据库，不自动上传附件。
```
